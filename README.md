# @Film (web)

La web de [@Film](https://film.useaify.app), el editor de vídeo gratis para gestores de redes de [Aify](https://www.useaify.app): la landing y el editor en `/app/`.

El editor es [aify-film](https://github.com/dylanstillavato/aify-film), un fork de [FilmCraft](https://github.com/storytold/filmcraft), compilado a WebAssembly con `scripts/publicar-editor.sh`.

```sh
npm install
npm run dev
```

El editor de `public/app/` lleva su licencia (MIT o Apache-2.0, ver `public/app/NOTICE`).
